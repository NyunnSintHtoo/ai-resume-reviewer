# Job Description: Backend Software Engineer (Python)

**Company:** Nimbus Analytics (Series B, ~120 people)
**Location:** Remote (US) | **Level:** Mid (2-5 yrs)

## About the role

Build and operate the APIs powering our analytics platform used by 900+ customers.

## Responsibilities

- Design and implement REST APIs with Python (FastAPI or Django REST Framework)
- Model and optimize PostgreSQL schemas; write efficient SQL
- Add caching (Redis) and asynchronous background processing (Celery or similar)
- Own services in production: monitoring, alerting, incident response
- Write unit and integration tests; participate in code review

## Requirements

- 2+ years of professional backend experience with Python
- Strong SQL and PostgreSQL experience; understanding of indexing and query plans
- Experience with Docker and at least one cloud (GCP, AWS)
- Familiarity with CI/CD pipelines and automated testing (pytest)

## Nice to have

- Kubernetes, Terraform, event streaming (Kafka / PubSub), gRPC
- Experience with LLM-powered features or vector search
