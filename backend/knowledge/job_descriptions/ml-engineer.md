# Job Description: Machine Learning Engineer (LLM Applications)

**Company:** Arcadia Labs
**Location:** SF or Remote | **Level:** Mid-Senior (3-7 yrs)

## Responsibilities

- Build LLM-powered product features: prompt engineering, RAG pipelines, agentic workflows, evals
- Design retrieval systems (chunking, embeddings, vector stores, reranking)
- Ship and operate model-serving infrastructure with caching and cost controls
- Establish offline/online evaluation for quality, latency, and safety

## Requirements

- 3+ years of software or ML engineering; strong Python
- Hands-on experience with LLM APIs (Anthropic, OpenAI) in production
- Understanding of retrieval-augmented generation and embedding models
- API development (FastAPI/Flask), PostgreSQL, Redis, Docker

## Nice to have

- Fine-tuning experience, TypeScript/React, Kubernetes, streaming inference, guardrails frameworks
