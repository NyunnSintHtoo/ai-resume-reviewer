# Job Description: Software Engineer, New Grad

**Company:** Vantage Systems (public, 4,000 people)
**Location:** Seattle, WA | **Level:** Entry (0-1 yrs)

## Responsibilities

- Implement well-scoped features across backend services and web frontends
- Write tested, reviewed code in Python, Java, or TypeScript
- Debug production issues with guidance from senior engineers
- Participate in design discussions and sprint planning

## Requirements

- BS/MS in Computer Science or equivalent practical experience (graduating within 12 months)
- Strong CS fundamentals: data structures, algorithms, complexity
- Proficiency in at least one of Python, Java, C++, or TypeScript
- Internship, research, or substantial project experience building real software

## Nice to have

- Full-stack projects with deployed demos, open-source contributions, hackathon wins
- Familiarity with SQL, Git workflows, cloud platforms, and testing frameworks
