# Job Description: Frontend Engineer (React/Next.js)

**Company:** Brightline Health (Series C)
**Location:** Hybrid, NYC | **Level:** Mid-Senior (3-6 yrs)

## Responsibilities

- Build patient-facing web apps with React, Next.js (App Router), and TypeScript
- Implement accessible, responsive UI from Figma designs with Tailwind CSS
- Own client-side data fetching, caching, and state management
- Improve Core Web Vitals and bundle size; add frontend observability
- Collaborate with design and backend teams on API contracts

## Requirements

- 3+ years building production React applications
- Strong TypeScript; deep understanding of hooks, rendering, and suspense
- Experience with Next.js, SSR/SSG, and modern build tooling
- Testing with Jest / React Testing Library / Playwright
- Accessibility (WCAG) fundamentals

## Nice to have

- Design systems, Storybook, GraphQL, healthcare domain experience
