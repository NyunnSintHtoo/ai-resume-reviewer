# Job Description: Full-Stack Software Engineer

**Company:** Corely (seed stage, 15 people)
**Location:** Remote | **Level:** Early-Mid (1-4 yrs)

## Responsibilities

- Ship features end-to-end: FastAPI backend, React/Next.js frontend, PostgreSQL
- Design REST APIs and simple, correct data models
- Build internal dashboards and customer-facing flows with authentication
- Deploy and operate services on Google Cloud (Cloud Run, Cloud SQL)
- Move fast with tests where they matter; help set engineering norms

## Requirements

- 1+ years of professional experience (or exceptional projects) across the stack
- Python and TypeScript proficiency
- SQL fundamentals; comfort with schema design and migrations
- Git, code review, and CI/CD basics
- Ownership mindset — you take features from idea to production

## Nice to have

- Docker, Redis, LLM API integration (OpenAI/Anthropic), Stripe, analytics tooling
