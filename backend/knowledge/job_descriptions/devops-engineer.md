# Job Description: DevOps / Platform Engineer

**Company:** Beacon Fintech
**Location:** Remote (US) | **Level:** Mid (2-5 yrs)

## Responsibilities

- Own CI/CD pipelines (GitHub Actions) and deployment automation
- Manage Kubernetes clusters and infrastructure-as-code (Terraform) on GCP
- Build observability: metrics, logs, traces, SLOs, on-call tooling
- Harden security: secrets management, IAM, network policies, compliance evidence

## Requirements

- 2+ years in DevOps/SRE/platform roles
- Strong Linux, networking, and scripting (Python or Bash)
- Production Kubernetes and Docker experience
- Terraform or equivalent IaC; cloud cost awareness

## Nice to have

- GCP professional certification, service mesh, supply-chain security (SLSA), fintech compliance (SOC 2)
