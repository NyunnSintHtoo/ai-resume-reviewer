# Projects Section for Engineers

Projects matter most for students, career changers, and anyone whose day job doesn't show a target skill. Each project gets: name, one-line stack summary, and 1-3 outcome bullets with links (GitHub / live demo).

> **AI Resume Reviewer** — FastAPI, Next.js, PostgreSQL, Claude API
> - Built a full-stack review tool with an agentic LLM pipeline and RAG over best-practice docs; deployed on Cloud Run.

## What makes a project credible

- It is deployed or runnable, with a README and tests.
- It solves a real problem, however small.
- Bullets state what you engineered (caching, auth, async processing), not just what the app does.
