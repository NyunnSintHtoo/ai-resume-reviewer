# The Skills Section Done Right

Group skills by category and order by relevance to the target role:

- **Languages:** Python, TypeScript, Go, SQL
- **Frameworks:** FastAPI, React, Next.js, Django
- **Infrastructure:** PostgreSQL, Redis, Docker, Kubernetes, GCP, AWS
- **Practices:** CI/CD, observability, code review, agile

## Rules

1. Only list skills you can defend in an interview.
2. No proficiency bars or percentages — they are unparseable and self-undermining.
3. Cut ubiquitous non-signals (Microsoft Word, email) and soft skills (communication) — demonstrate those in bullets instead.
4. Mirror the job description's exact terms for your true skills.
