# Links, GitHub, and Supporting Materials

- **GitHub:** pin 2-4 repos with real READMEs; recruiters click one link and spend under a minute.
- **LinkedIn:** must match resume dates and titles — discrepancies read as dishonesty.
- **Portfolio / personal site:** only link if it is current and loads fast.
- Put links as visible text (github.com/name) so they survive printing and ATS parsing.
- Cover letters: three short paragraphs — why this company, evidence you can do this job, close with logistics. Only write one when the application asks or the company is small.
